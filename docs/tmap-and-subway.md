# TMAP·지하철 데이터 명세

## 지도

TMAP Vector Map SDK 3.7의 Android/iOS 네이티브 뷰가 지도를 렌더링한다.
정류장·선택 장소·노선·길찾기 경로를 표시하며 버스 차량 위치는 지도에 표시하지 않는다.
React 연결은 `shared/ui/tmap/tmap-view.tsx`, 플랫폼 구현은 `modules/tarago-tmap`에 있다.

## 인증 변수

| 변수                                    | 사용 위치·역할                                               |
| --------------------------------------- | ------------------------------------------------------------ |
| `TMAP_API_KEY`                          | 서버의 장소 검색·보행자·대중교통 경로와 모바일 지도 SDK 인증 |
| `SEOUL_SUBWAY_REALTIME_ARRIVAL_API_KEY` | 서버의 서울 지하철 실시간·역 정보·시간표·시설 조회           |
| `EXPO_PUBLIC_API_BASE_URL`              | 앱에서 접근하는 타라고 API의 공개 주소                       |

지도 SDK는 기기에서 인증하므로 TMAP 모바일 키가 바이너리에 포함된다.
`plugins/with-tmap.js`가 빌드 환경의 값을 Info.plist·AndroidManifest에 주입한다.
다른 공공데이터 인증키는 서버에만 존재한다.

## 서버 응답

| 경로                   | 역할                                         |
| ---------------------- | -------------------------------------------- |
| `/mobility/places`     | TMAP 장소·주소 검색                          |
| `/mobility/directions` | TMAP 보행자·대중교통 경로와 공급자 구간 좌표 |
| `/subway/arrivals`     | 서울시 열차 실시간 도착정보                  |
| `/subway/station`      | 역·노선·인접역·연락처 정보                   |
| `/subway/timetable`    | 요일 구분별 공식 시간표와 첫차·막차          |
| `/subway/facilities`   | 제공기관의 역 시설 자료                      |

앱의 Query는 조회 결과·취소·캐시·화면 활성 중 폴링을 관리한다.
서버의 실시간 지하철 응답에는 15초 캐시와 동일 요청 병합이 적용된다.
수신 시각은 한국 시간으로 해석하며 오래된 도착 응답은 갱신 지연으로 표시된다.

## 제공 범위

TMAP 버스 모드는 최대 10개 경로 응답 중 버스·도보로 구성된 경로를 선택한다.
기차·항공·해운 등 지원하지 않는 이동수단을 도보로 변환하지 않는다.
지하철은 연결된 공공 API의 제공 역·노선을 지원한다.
일부 기관의 서버 통신은 공식 HTTP 주소를 사용하며 앱과 타라고 서버 사이 통신은 HTTPS다.

## 빌드 구성

공식 SDK 바이너리는 Git에서 제외되며 EAS의 `eas-build-pre-install`이 플랫폼 SDK를 복원한다.
설치 스크립트는 HTTPS·체크섬·압축 경로를 검증한다.
Expo prebuild는 config plugin으로 네이티브 설정을 생성한다.
네이티브 SDK·모듈·권한 변경은 JS 번들 갱신과 구분되는 네이티브 빌드 변경이다.
