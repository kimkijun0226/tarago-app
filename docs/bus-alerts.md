# 버스 알림 사용과 실행 준비

버스 시간 오른쪽의 종 버튼을 누르면 선택한 정류소·노선의 알림 설정 화면이 열린다. 알림 목록에서는 설정 수정, 사용 여부 변경, 삭제가 가능하다.

- 예약 도착 알림: 반복 요일, 한국 시간 기준 감시 시작·종료 시각, 도착 1~30분 전 기준을 설정한다. 서버가 15초 간격으로 감시한다. 자정을 넘으면 시작한 날의 요일을 적용한다. 도착정보가 없어도 감시 종료까지 조회를 계속한다.
- 정류소 접근 알림: 예약 시간·요일과 관계없이 설정한 정류소의 100/200/300m 이내에 접근하면 그 정류소 전체 버스의 현재 ETA를 알려준다. 기본값은 200m다. GPS 흔들림을 막기 위해 재진입 알림에 5분 간격을 두며 머무르는 동안 반복하지 않는다. 네트워크 조회가 실패하면 ETA를 지어내지 않고 재조회 안내를 보낸다.

## 서버

기존 정류장 마이그레이션 이후 알림 테이블을 적용한다.

```sh
cd server
npm run migrate:alerts
npm run build
npm run start:prod
```

기존 `start:dev`도 감시 Worker를 실행한다. 알림은 PostgreSQL에 저장되므로 서버를 재시작해도 설정과 중복 발송 기록을 유지한다. 같은 정류장의 조회는 기존 도착 캐시를 공유한다. 알림 API는 SecureStore에 저장한 기기별 무작위 자격 증명으로 접근하며 다른 기기의 알림은 읽거나 수정하지 못한다.

## 앱 빌드와 실기기

알림·작업·SQLite·보안 저장 모듈을 추가했으므로 기존 개발 앱을 다시 빌드해야 한다. Expo Go에서는 이 앱의 지오펜싱을 검증할 수 없다.

```sh
cd app
npx expo prebuild
npx expo run:ios --no-bundler
# Android 개발 앱을 사용하는 경우
npx expo run:android --no-bundler
npm run start:simulator
```

실기기에서는 `EXPO_PUBLIC_API_BASE_URL`에 접근 가능한 서버 주소를 지정한다. 운영 서버는 HTTPS를 사용한다.

예약 푸시에는 EAS 프로젝트 연결 및 플랫폼별 APNs/FCM 자격 증명이 필요하다. 연결된 프로젝트의 `extra.eas.projectId` 또는 `EXPO_PUBLIC_EAS_PROJECT_ID`를 사용한다. 알림 설정 저장 시 Expo 푸시 토큰을 서버에 등록하며, 앱의 토큰 변경 이벤트에도 재등록한다. 프로젝트·자격 증명이 없으면 예약 알림을 설정해 둘 수 있지만 **푸시 연결 필요**로 표시되고 전송은 시작되지 않는다. 연결 완료 후 알림 화면의 **푸시 다시 연결**을 누른다. 실제 외부 프로젝트 생성·계정 로그인·푸시 자격 증명 등록은 이 코드 변경에 포함되지 않는다.

접근 알림은 원격 푸시와 별개로 로컬 알림을 사용하며 알림 권한과 위치 ‘항상 허용’ 권한이 필요하다. 사용자 GPS 좌표나 이동 경로를 서버에 저장하지 않는다. 기기에는 선택 정류소의 설정만 백그라운드 작업용 사본으로 저장한다.

## 플랫폼 제한과 알림 빈도

- iOS의 지오펜스 제한에 맞춰 기기당 최대 20개 알림을 저장한다. 같은 정류소의 여러 노선은 한 영역으로 합친다.
- GPS와 OS 절전 정책에 따라 접근 감지에 지연이 있을 수 있다. Android에서 강제 종료하면 감지가 멈출 수 있다. 항상 실행을 보장하는 기능으로 안내하지 않는다.
- 예약 알림은 감시일·설정 시간 범위·임계값·차량 ID마다 한 번 발송한다. 같은 차량이 같은 감시 범위 안에서 여러 번 운행해도 한 번만 알린다. 공급자가 차량 ID를 제공하지 않으면 해당 노선의 감시 범위에서 한 번만 발송한다.
- 외부 푸시 실패는 최대 3번 시도하며, 영수증에서 만료된 토큰이 확인되면 그 토큰의 등록을 비활성화한다. 네트워크 단절 시 푸시 서비스의 접수 성공 여부를 완전히 확정할 수 없으므로 모든 상황에서 정확히 한 번 전달되지는 않는다.

## 검증

```sh
cd app
npm test
npx tsc --noEmit
npm run lint
cd ../server
npm test -- --runInBand --watchman=false
npm run lint
npm run build
# 로컬 API가 실행 중이고 정류소 데이터가 준비된 경우
npm run test:alerts:integration
```

예약 푸시와 실제 이동에 따른 백그라운드 알림은 권한을 허용한 실기기에서 최종 확인해야 한다.
