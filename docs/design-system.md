# TaraGo 디자인 기준

2026-10-31 사용자 수정 요청을 반영한 최신 기준. 기존 게임 UI 및 radius 0·무채색 고정 규칙보다 우선한다.

## 브랜드

**기다림은 맡기고, 내 시간에 타다.**

버스가 언제 오는지 반복해서 확인하느라 내 시간을 쓰지 않도록, 미리 정한 시간이나 정류소 근처에서 필요한 도착정보를 전한다. 예약은 하루의 계획, 버스는 실제 이동, 알림은 두 순간을 이어주는 신호다. 지하철에도 같은 약속을 적용한다.

심볼은 사용자가 확정한 1번 H: 흰 배경 위 파란 교통 말풍선과 두 갈래 상단 요소로 구성한다. 입체 질감·그라데이션·인위적인 광택·캐릭터 종은 사용하지 않는다. 로고는 심볼과 TaraGo 워드마크를 함께 사용한다. 브랜드 문구를 매 화면의 설명문으로 반복하지 않는다.

## 색상

- 흰색 #FFFFFF 중심. 보조 표면 #F5F9FF. 베이지·아이보리·골드 배경 금지.
- 본문 #1B2D48, 보조 본문 #465873, 설명 #586B86, 구분선 #E3EAF4.
- 실행·선택: 파랑 #2468D4, 브랜드 심볼 #3385F5. 선택 배경 #ECF4FF. 모든 아이콘과 제목에 파랑을 반복하지 않는다.
- 브랜드 강조와 읽지 않은 알림 점은 파랑으로 통일한다. 노랑은 브랜드 장식에 사용하지 않고 실제 경고 상태의 의미색만 유지한다.
- 교통 노선 공식색은 식별 정보로 보존한다. 오류·경고는 의미색을 유지한다.
- 색상·라운드·그림자는 src/shared/ui/theme.ts에서 관리한다.

## 컴포넌트

- 컨트롤·입력·선택 영역은 14px, 카드·시트는 16px 라운드. 작은 배지는 6–8px, 핸들은 2px 라운드. 알림 점과 노선 도식의 원은 원형을 유지한다.
- 그림자는 지도 위 검색창·내 위치·시트처럼 배경에서 분리되어야 하는 표면에만 얕게 적용한다. 일반 목록과 수정·삭제 아이콘은 평면으로 유지한다.
- 헤더 아이콘에 장식 배경을 넣지 않는다. 44px 이상 터치 영역과 접근성 레이블을 유지한다.
- 좌우 여백은 일반 화면 20px, 지도 목록 16px. 제목과 본문의 시작선을 맞춘다.
- 제목은 600, 본문 400–500. 제목과 설명의 간격은 4px. 시간은 숫자 고정폭과 선명한 대비로 강조한다.
- 저장 알림은 내용 높이에 맞추고 항목 사이 구분선을 사용한다. 설정 폼에 이중 테두리와 불필요한 장식을 넣지 않는다.
- 누름 피드백은 표면색 또는 투명도. 게임식 튀김·두꺼운 입체 테두리를 넣지 않는다.

## 자산과 시작 화면

- assets/brand/에 SVG 원본과 PNG 결과물을 함께 둔다. scripts/generate-brand-assets.cjs로 PNG를 재생성한다.
- iOS·Android 앱 아이콘과 네이티브 스플래시는 app.json에서 설정한다. iOS Expo 기본 .icon 파일을 더 이상 참조하지 않는다.
- 시작 화면은 흰색 위 파란 심볼. React 전환 레이어도 같은 심볼·크기·배경을 사용한다.
- 네이티브 아이콘과 시작 화면 반영은 prebuild 및 앱 재빌드가 필요하다. 개발 클라이언트 자체 화면과 최종 Release 시작 화면은 다를 수 있다.

## 범위

알림·지도 컨트롤·검색·교통 상세·시간표·의견 보내기에 적용한다. API·위치 조건·알림 규칙·지도 좌표는 변경하지 않는다.

## 밝고 귀여운 알림 브랜드

사용자의 최신 선호는 밝고 깨끗한 파랑이다. 초록·청록 기가 있는 배경과 본문을 제거한다. 흰색을 중심으로 하늘색 선택 영역을 사용하고, 알림 점에도 같은 파랑을 쓴다. 평면 2D 교통수단과 12–16px 라운드로 친근함을 주고, 글씨는 시스템 글꼴과 명확한 대비를 유지한다.

검색 버스 마커는 하늘색 #199CCB, 지하철은 기존 파랑, 출구는 작은 황토색 포인트 #B58229로 구분한다. 마커 이미지의 크기·알파 윤곽·앵커·좌표는 바꾸지 않는다.

## 선택 상태의 고정 레이아웃

- 선택 전후에 자식의 수·크기·간격·패딩·정렬·테두리 두께를 바꾸지 않는다. 선택됐을 때만 체크·아이콘·설명을 삽입하지 않는다.
- 기본 상태에서도 같은 테두리 너비를 확보하고 색상만 바꾼다. 선택 텍스트의 글꼴·크기·굵기·행간도 유지한다.
- 복수 선택은 배경색·테두리색·글자색과 accessibilityState.checked로 표시한다. 시각적 체크마크는 추가하지 않는다.
- 카드 안의 아이콘과 글자는 공통 기준선·고정 간격으로 정렬한다. 장식은 글씨 영역을 밀거나 정보의 우선순위를 흐리지 않는다.

## 지도 시트와 탭 — 2026-11-01

기본·최소 높이는 시트 좌우 12px, 아래는 안전 영역 또는 최소 12px를 띄운다. 최대 높이는 좌우·아래 여백을 없애고 위 안전 영역 아래 8px를 남긴다. 단계 사이 여백은 시트 애니메이션을 따라 보간한다. 내 위치 버튼은 이 외곽 이동이 반영된 시트 상단을 따른다.

지도에서 설정한 탭 숨김은 지도에 초점이 있을 때만 적용한다. 알림 저장 후 목록과 의견 탭에서는 하단 탭을 표시한다.

위치 알림 설명은 권한이 미설정된 경우 ‘항상’ 허용이 필요한 이유를 보여준다. 권한 조회는 자동으로 할 수 있지만 요청은 사용자가 설정하기를 누른 뒤에만 시작한다. 이미 거절됐으면 설정 앱 이동 경로를 안내한다.

### 오류와 복구

- 사용자 조치가 필요한 오류만 상단 에러 토스트로 안내한다. 노란 배너·카드로 레이아웃을 밀어내지 않는다. 오류가 해소될 때까지 유지하며 자동 타이머나 닫기 버튼으로 숨기지 않는다. 지속되는 오류에는 문의하기를 제공한다.
- 시작·백그라운드 조회는 Query의 재시도로 처리하며 전체 화면을 잠그거나 공통 복구 실패 토스트를 띄우지 않는다. 사용자가 재연결을 선택한 경우에만 실제 요청 중 로딩과 조작 차단을 표시하고, 8초 이상 화면을 잠그지 않는다.
- 권한 설정은 사용자가 선택해 이동하며, 저장·삭제 요청은 자동으로 반복하지 않는다.

### 단계 표시와 화면 가림 방지

- 알림과 즐겨찾기은 작은 탐색 헤더 아래 번호·단계명으로 진행 상태를 보여주고, 그 아래 질문형 큰 제목을 배치한다. 즐겨찾기 선택 영역은 남은 화면을 위아래로 채운다.
- 알림·즐겨찾기·의견 탭은 자동 탭 inset을 끄고 react-native-screens의 네이티브 SafeAreaView로 실제 탭 영역을 확보한다. 임의의 탭 높이를 더하지 않는다.
- 입력 화면은 ScrollView의 iOS 키보드 inset과 Android 기본 resize를 사용한다. KeyboardAvoidingView와 자동 키보드 inset을 겹쳐 적용하지 않는다. 목록 끝에는 기본 24 여백만 둔다.

### 설정 진입과 선택 옵션

- 예약 추가·즐겨찾기 추가는 SetupHeader로 탐색 헤더 → 단계 표시 → 질문형 제목의 위계를 통일한다. 단계 표시를 삭제하거나 탐색 제목 자리에 넣지 않는다. 예약·위치 알림 아래 안내 카드는 전체가 하나의 버튼이다. 내부에 별도 채움 버튼을 중첩하지 않고 설정하기·작은 화살표로 이동을 안내한다.
- 예약·위치 알림은 독립된 선택 카드로 구분하며 선택 전후 크기·글자 위치를 유지한다. 알림 추가 중간 단계에는 설명문을 넣지 않고 최종 설정 끝에 짧은 안내만 둔다.
- 최종 알림 설정은 60ms 간격의 짧은 진입 애니메이션을 사용하고, 입력값 갱신에는 반복하지 않는다. OS 동작 줄이기를 존중한다.
- 새 예약은 음성 알림과 버스 번호판 표시를 끈 상태로 시작하고 설정 마지막에 배치한다. 기존 예약의 저장된 값은 유지한다.

### 간격 정리 — 2026-11-03

- 토스 DESIGN.md 참고: https://oh-my-design.kr/ko/design-systems/toss . 공식 UX 가이드: https://developers-apps-in-toss.toss.im/design/consumer-ux-guide.md . 서드파티 정리본의 수치를 토스 네이티브 전체의 규칙으로 단정하지 않는다.
- 타라고 적용 기준: 화면 좌우·카드 내부·섹션 간격 16, 연관 요소 8, 제목과 부제 4. 헤더 위에는 Safe Area 외 4만 추가한다. 헤더와 단계·제목 간격은 8이다.
- 중첩된 바깥/안쪽 패딩과 의미 없는 최소 높이를 늘리지 않는다. Safe Area·키보드 inset·44 이상의 터치 영역은 유지한다.
- 브랜드 파랑과 흰 카드, 14–16 라운드를 유지하고 강한 채움색은 필요한 주요 행동에만 쓴다.

### 지도 바텀시트 공통 기준 — 2026-11-03

- 버스 정류소·노선·지하철·검색 결과·알림/즐겨찾기 선택 시트는 MapBottomSheet의 동일한 표면·핸들·툴바 규격을 사용한다. 토스 DESIGN.md의 평면 표면과 정보 위계를 참고한 타라고 규격이며 토스 원본 수치라고 단정하지 않는다.
- 핸들 영역은 20(상하 8 + 표시 4). 시트 높이·목록 높이·정착 콜백 계산에도 같은 상수를 쓴다. 툴바 좌우 16·아래 8, 본문 좌우 16·연관 요소 8·제목과 부제 4.
- 기본/접힘 상태의 외곽 여백은 유지하고 최대 확장 시 외곽 여백은 사라진다. 최대 확장 목록은 홈 인디케이터 안전 영역을 제외한 높이를 쓴다.
- 시트 테두리를 제거하고 흰 표면·얕은 외곽 그림자로 구분한다. 목록은 헤더와 같은 시작선을 따른다. 최대 확장의 지도 딤은 과도하게 어둡지 않게 한다.
- 버스 새로고침은 시트 내부 하단의 44 높이 행으로 배치한다. 목록 위에 띄우거나 버튼 회피를 위한 110 여백을 두지 않는다. 목록 끝 기본 여백은 16이다.

### 알림 추가 문구와 위치 권한 — 2026-11-03

- 선택 화면은 질문형 제목·스텝·선택 항목만 표시한다. 예약/위치 선택 아래에 같은 설명을 반복하거나 위치 권한의 사용법을 상시 나열하지 않는다.
- 지도 진입 카드는 교통 아이콘·정류소와 버스 선택/역과 방면 선택·화살표만 보여주며 전체가 하나의 버튼이다. 설명은 최종 설정 끝에 한 문장만 둔다.
- 앱 시작·지도 초기화·자동 재조회에서는 위치 권한을 요청하지 않는다. 기존 허용 상태로만 위치를 조회하고, 허용되지 않았으면 기본 지도와 검색을 제공한다.
- 위치 알림 설정 진입에서 필요한 전경/백그라운드 권한을 요청한다. 내 위치 버튼은 명시적으로 눌렀을 때 전경 권한을 요청할 수 있다. 예약 알림 자체에는 위치 권한이 필요하지 않다.

### 알림 추가의 설명 카드 — 2026-11-03 후속

- 예약·위치 알림은 위아래 두 개의 카드로 남은 화면을 반씩 채운다. 각 카드에 제목·한 문장 설명·조건 아이콘·화살표를 포함하며, 아래 별도 설정 영역을 두지 않는다.
- 진입 시 두 카드가 60ms 간격으로 220ms 동안 짧게 나타나고, 카드 터치 시 전체를 0.985배로 눌렀다가 돌아온다. 이는 토스를 참고한 타라고 자체 모션 값이며 토스 공식 토큰으로 표시하지 않는다. 동작 줄이기를 존중한다.
- 초기 선택 화면의 핵심 설명과 음성 알림 한 줄 설명은 유지한다. 권한 사용법·같은 의미의 중복 문장은 나열하지 않는다.
- 헤더의 추가 상단 패딩은 0, 헤더·단계·제목 사이 간격은 4. 안전 영역과 터치 영역은 보존한다. 대시보드와 설정의 큰 제목은 한 줄에 맞춰 크기를 조정한다.

### 알림 종류 선택 — 즐겨찾기 추가와 동일한 구성

- 예약 알림과 위치 알림은 위아래 두 개의 큰 카드로 남은 화면을 반씩 채운다. 아래 별도 설정 카드나 추가 버튼을 두지 않는다.
- 각 카드에 조건 아이콘·종류 제목·짧은 설명·화살표를 배치한다. 카드 전체가 버튼이며 선택 즉시 해당 종류의 지도 선택으로 이동한다.
- 위치 권한은 위치 카드로 설정을 시작할 때만 요청한다. 두 카드가 표시되는 시점에는 요청하지 않는다.

- ON/OFF 스위치는 손잡이 이동과 배경색 전환에 짧은 ease-in-out 애니메이션을 적용한다. OS 동작 줄이기를 존중한다. 알림 상태 변경 시 기존 카드 순서는 유지한다. 도착정보가 없거나 조회가 비활성화되면 빈 높이를 예약하지 않는다.

- 동일한 의미의 아이콘은 기존 공통 컴포넌트를 재사용한다. 알림 목록 왼쪽 교통 아이콘은 TransportIcon을 유지한다. 번호·호선명과 같은 크기로 예약 알림·위치 알림을 표시하고, 그 오른쪽에 기존 clock/schedule 또는 location/near_me 아이콘을 배경 없이 배치한다. 별도 복합 아이콘을 만들지 않는다.

- 넓은 선택 카드는 흰 배경과 아주 옅은 그림자(불투명도 0.04, 아래 2px, 반경 8px)를 사용한다. 예약·위치 선택 카드의 오른쪽 화살표는 표시하지 않는다.
