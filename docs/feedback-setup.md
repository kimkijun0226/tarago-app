# 의견 보내기

앱 하단의 의견 보내기 탭에서 제목(필수, 최대 100자), 내용(선택, 최대 5,000자), 이미지 1장(선택, JPG/PNG/WebP 최대 5MB)을 보낸다.

서버는 기기 인증 후 Gmail SMTP로 전송한다. Gmail이 메일을 수락한 뒤에만 앱에 성공을 반환한다. 실패하면 작성 내용은 유지된다. 메일함 도착 시각은 Gmail 처리에 따라 달라질 수 있다.

서버 환경 변수:

- `FEEDBACK_TO`: `kimkijun0226@gmail.com`
- `GMAIL_USER`: 발송에 사용할 Gmail 주소
- `GMAIL_APP_PASSWORD`: 해당 계정의 앱 비밀번호. 일반 로그인 비밀번호를 사용하지 않는다.

Google 계정에서 2단계 인증을 설정한 뒤 https://myaccount.google.com/apppasswords 에서 앱 비밀번호를 발급한다. 비밀 값은 서버의 `.env.local` 또는 배포 환경의 비밀 변수에만 저장하고 커밋하지 않는다. 설정 후 서버를 재시작한다. 설정이 없으면 성공으로 처리하지 않고 503을 반환한다.

앱에 `expo-image-picker` 네이티브 모듈이 추가되어 iOS/Android 개발 빌드 및 배포 빌드를 새로 만들어야 한다. Metro 재시작만으로는 기존 설치 앱에 모듈이 추가되지 않는다.

메일 발송 연동 확인은 Gmail 계정 설정 후 제목만 보내기, 내용 포함 보내기, 이미지 포함 보내기로 확인한다. 자동 재시도는 하지 않는다.
