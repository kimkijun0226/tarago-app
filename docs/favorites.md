# 앱 즐겨찾기

홈 화면 WidgetKit 확장은 제거하고 앱의 ‘즐겨찾기’ 탭에서 버스·지하철을 그룹별로 관리합니다. 내부 `/widgets`, `/widget-add`, `/widget-map`, `/widget-direction` 경로는 기존 이동 경로와의 호환성을 위해 유지합니다.

## 그룹과 배치

- 기본 그룹은 ‘집 근처’이며, 그룹 추가·이름 변경·삭제를 지원합니다.
- 그룹마다 원형 항목을 왼쪽부터 가로 네 칸씩 배치합니다.
- 첫 줄은 빈 상태에서도 점선 원과 중앙 `+`가 있는 네 칸을 표시합니다.
- 네 항목이 채워지면 둘째 줄 첫 칸인 다섯 번째 자리에 추가 버튼이 생깁니다. 그 이후에는 항목 바로 다음 칸에 추가 버튼 하나를 표시합니다.
- 추가 버튼은 해당 그룹을 선택하고 기존 교통수단 → 지도 → 방면 선택으로 이어집니다.
- 항목을 누르면 지도 상세를 열고, 길게 누르면 순서 변경·삭제 메뉴를 표시합니다. 기존 홈 위젯의 12개 제한은 없습니다.

## 저장과 조회

그룹별 선택 조건은 `tarago-favorite-groups-v1-<서버 범위>`에 저장합니다. 기존 `tarago-widget-targets-v2-<서버 범위>` 목록은 ‘집 근처’ 그룹으로 옮기고, 원래 저장값은 보존합니다. 같은 항목은 그룹마다 독립적으로 저장할 수 있고 한 그룹 안에서는 중복을 막습니다. 저장 실패 시 메모리의 그룹과 항목을 먼저 변경하지 않습니다.

도착정보는 TanStack Query가 관리합니다. 즐겨찾기 화면에 초점이 있을 때 기존 정류장·역 Query로 조회하고 화면을 벗어나면 전용 폴링을 중지합니다. 화면의 카운트다운은 1초마다 계산하고 서버 조회는 기존 화면별 주기를 사용합니다. 앱 전체에서 수행하는 즐겨찾기 조회나 네이티브 위젯 동기화는 없습니다.

## 네이티브 제거

`with-removed-transit-widget` 플러그인은 이미 생성된 iOS 프로젝트에서도 `TaraGoWidgets` 타깃·소스 참조·제품 임베드·의존성을 제거합니다. WidgetKit Swift 코드와 `TaraGoWidgetBridge` Expo 모듈은 삭제했습니다. 알림 확장과 Scheme은 유지합니다. 이름에 widgets가 들어 있는 기존 App Group은 음성 알림도 사용하므로 유지하며, 이것으로 홈 위젯이 생성되지는 않습니다.

기존 설치 앱의 홈 위젯 지원을 없애려면 확장 제거가 반영된 새 앱 빌드를 설치해야 합니다.
