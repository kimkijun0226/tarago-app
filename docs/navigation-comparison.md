## 데이터와 확인 범위

타라고의 장소·경로 데이터는 TMAP과 자체 서버를 사용한다. 네이버의 순위 산정, 전용 실시간 탑승 예측, 예약 출발 시각, 계단 제외 옵션, 자동차·자전거 경로는 현재 계약에 없다. 제공하지 않는 값을 추정하거나 동작하지 않는 선택 버튼을 추가하지 않는다. 현재 출발 기준의 시간 범위는 시간표에 따른 정확한 열차 출발 시각을 뜻하지 않는다.

지도 자체의 도로·건물 표시는 네이버 지도 SDK의 데이터와 스타일이다. 검색·길찾기의 화면 구성과 상태 전환 비교와 구분된다.
