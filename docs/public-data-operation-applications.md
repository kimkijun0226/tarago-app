# 타라고 공공데이터 운영계정 신청서

공공데이터 운영계정의 활용사례 등록용 서비스 설명.

## 경기도 버스

활용사례명

타라고 – 경기도 버스 실시간 도착정보 및 맞춤 알림

서비스 URL (현재 내부 배포용)

https://expo.dev/accounts/kimkijun/projects/tarago/builds/b985735b-033b-4930-9064-dbbeb452b129

서비스 설명

타라고는 iOS·Android에서 주변 정류장과 버스 도착정보를 확인하고, 선택한 요일·시간에 버스 도착 알림을 받는 모바일 대중교통 앱입니다. 경기도 버스도착정보 API로 정류장별 첫 번째·두 번째 차량의 도착예정시간과 남은 정류장 수를 표시합니다. 알림에는 최대 두 차량의 정보를 하나의 메시지로 제공합니다. 현재 내부 배포를 통해 기능과 운영 안정성을 검증 중입니다. 이용자가 지정한 시간 범위 안에서만 알림을 감시하고, 서버 공통 캐시와 동시 요청 병합으로 같은 정류장의 중복 조회를 줄입니다. 개발계정 일일 1,000회로는 실시간 화면과 시간대 알림을 함께 검증하기 어려워 운영계정 전환을 신청합니다.

기능 및 서비스 화면

1. 지도 화면: 현재 위치와 주변 버스 정류장을 표시하고 정류장 선택 시 운행 노선 목록을 제공합니다.
2. 도착정보 화면: 노선별 첫 번째·두 번째 버스의 도착예정시간, 남은 정류장 수, 제공되는 차량번호 뒷자리 정보를 표시합니다. 도착정보가 없으면 정보 없음 상태를 안내합니다.
3. 시간 알림: 정류장·노선·요일·시작 및 종료시간을 선택합니다. 해당 시간 범위에서만 도착정보를 확인하고 사용자가 설정한 도착 단계에서 알림을 전송합니다.
4. 위치 기반 알림: 선택 정류장 500m 이내 접근 시 도착알림 시작을 안내합니다. 확인한 경우 별도의 1시간 알림 세션을 시작합니다.
5. 요청 관리: 동일 정류장의 응답 캐시와 진행 중 요청 병합, 오류 시 재시도 제한으로 중복 호출을 줄입니다. 앱이 화면을 표시하지 않을 때 화면용 주기 조회는 중단합니다.

서비스 설명

타라고는 iOS·Android에서 주변 정류장과 버스 도착정보를 확인하고, 선택한 요일·시간에 버스 도착 알림을 받는 모바일 대중교통 앱입니다. 서울특별시 정류소정보조회 API의 정류소고유번호 기반 도착정보를 활용해 노선별 첫 번째·두 번째 버스의 도착예정시간과 남은 정류장 수를 제공합니다. 최대 두 차량의 정보를 한 알림으로 묶고, 사용자가 지정한 시간 범위 안에서만 알림을 감시합니다. 서버 응답 캐시와 동일 정류장 동시 요청 병합으로 중복 조회를 줄입니다. 현재 내부 배포를 통해 기능과 운영 안정성을 검증 중이며, 개발계정 일일 1,000회로는 실시간 화면과 시간대 알림을 함께 검증하기 어려워 운영계정 전환을 신청합니다. 서울특별시 제공 데이터의 출처를 앱에 표시합니다.

기능 및 서비스 화면

1. 지도 화면: 현재 위치와 주변 정류장을 표시하고 정류장 선택 시 서울 버스 도착정보를 보여줍니다.
2. 도착정보 화면: 정류소고유번호로 조회한 노선별 첫 번째·두 번째 버스의 도착예정시간과 남은 정류장 수를 표시합니다. 제공되는 경우 차량번호 뒷자리도 안내합니다.
3. 시간 알림: 정류장·노선·요일·시간 범위를 설정하고 해당 범위에서만 도착정보를 감시합니다. 두 차량의 정보를 하나의 알림에 포함합니다.
4. 위치 기반 알림: 선택한 정류장 500m 이내 접근 시 알림 시작을 안내하고 확인 후 별도의 1시간 세션을 시작합니다.
5. 운영 관리: 서버 공통 캐시와 진행 중 요청 병합, 오류 재시도 제한으로 중복 호출을 줄이고 조회 실패를 사용자에게 안내합니다.
6. 출처 표시: 서울특별시 제공 버스정보임을 화면에 표시합니다.
