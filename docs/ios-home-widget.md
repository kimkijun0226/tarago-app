# iOS 홈 화면 위젯

## 화면

위젯 탭은 ‘위젯 리스트’ 제목과 직접 추가한 항목만 보여줍니다. 알림 예약 목록을 읽지 않으며 설명 카드를 표시하지 않습니다.

- + → 한 화면의 위·아래 버스/지하철 선택 영역(1단계) → 지도(2단계).
- 버스: 지도에서 정류소 선택 → 경유 버스 선택 즉시 위젯 추가.
- 지하철: 지도에서 역과 호선 선택 → 별도 방면 화면(3단계) → 방면 선택 즉시 위젯 추가. 방면 화면에서 뒤로가면 선택한 역의 지도·시트로 돌아갑니다. 지도 검색은 기존 검색 흐름을 사용합니다. 위젯은 /widget-map 경로와 독립된 mapSelection 상태로 진입하며 알림 탭이나 알림 선택 상태를 경유하지 않습니다.
- 최대 12개. 선택 순서를 유지하고 −로 삭제합니다. 알림 예약 생성·삭제·활성 상태와 독립적입니다.
- 앱 목록은 번호/호선·방면·도착 시간을 한 줄로, 정류장/역은 작은 보조 글씨로 표시합니다.

목록에는 등록된 총 개수와 최대 12개 제한을 표시하고, 아래에 작은·큰 위젯 미리보기를 제공합니다. 미리보기는 목록의 Query 캐시를 공유하며 별도 API 폴링을 시작하지 않습니다. 위젯 대상 선택은 알림 지도 패널을 재사용하되 예약 저장 API를 호출하지 않습니다.

## 홈 위젯

아이폰 홈 화면을 길게 누르고 편집 → 위젯 추가 → TaraGo 도착정보를 추가합니다.

- 작은 네모: 원형 2×2, 최대 4개.
- 가로 중간 크기: 원형 4×2, 최대 8개.
- 큰 크기: 원형 3×4, 최대 12개. 선택 순서대로 왼쪽에서 오른쪽, 위에서 아래로 배치합니다.
- 중앙에 교통편 아이콘과 버스 번호/호선을, 원의 12시 방향에 남은 시간을 표시합니다. 큰 위젯에는 방면과 시간표/예상 출처도 표시합니다.
- 원은 버스 종류별 뱃지 색상 또는 지하철 호선 색상을 사용하며 5분 이하에서는 남은 분에 맞춰 오른쪽부터 줄어듭니다. 시간은 5분 이하에서 iOS 시스템 타이머로 초 단위 표시하며 새 API 응답을 받으면 갱신된 도착 예정 시각을 기준으로 다시 맞춥니다. 원의 분 단위 갱신은 WidgetKit 타임라인을 사용하므로 실제 표시 시점은 iOS가 결정합니다. 빈 슬롯은 연한 원입니다.
- 위젯을 누르면 앱 위젯 리스트로 이동합니다. 오른쪽 아래의 작은 새로고침 아이콘은 iOS 17 이상에서 재조회를 요청합니다.

WidgetKit 확장이 앱과 독립적으로 기존 공개 도착 API를 조회합니다. 자동 갱신은 90초 이후를 요청하지만 실제 실행 시점은 iOS가 결정합니다. 30·60초에 ETA를 재계산하고 90초가 지나면 ‘갱신’을 표시합니다. 시간표·추정 ETA는 ‘약’으로 구분하고, 진입/도착은 숫자 ETA가 없어도 표시합니다.

## 데이터와 빌드

직접 선택한 조회 조건은 서버 주소별 SQLite 키 tarago-widget-targets-v2에 보관합니다. 이전 알림 ID 기반 선택은 가져오지 않습니다. 최신 도착정보는 TanStack Query가 관리하고, App Group에는 공개 조회 조건만 전달합니다. 인증 자격 증명은 공유하지 않습니다.

- Expo 플러그인: plugins/with-transit-widget.js
- 확장: TaraGoWidgets / com.anonymous.tarago.widgets
- Expo Pod: TaraGoWidgetBridge
- App Group: group.com.anonymous.tarago.widgets

이번 4/8/12개 원형 레이아웃과 최대 12개 지원은 네이티브 변경이므로 새 Archive/TestFlight 빌드가 필요합니다. 앱과 확장에는 동일 App Group이 포함된 서명이 필요합니다. 확장 버전은 prebuild 시 호스트 Xcode 설정을 따릅니다. 새 업로드 전 빌드 번호를 올려주세요. Android 홈 위젯은 아직 지원하지 않습니다.

실기기에서 새 빌드 설치 후 검색/추가/삭제/재실행 유지, 작은 크기 4개·가로 크기 8개·큰 크기 12개, 앱 종료 후 갱신, 반대 방면 제외 및 오프라인/만료 상태를 확인해야 합니다.
