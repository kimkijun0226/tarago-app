# TaraGo 전체 컴포넌트 재설계 계획

**Goal:** 12–16px 라운드·교통수단 캐릭터·명확한 글자 위계를 가진 귀여운 버스·지하철 알림 앱을 구현한다.
**Architecture:** 기존 공통 테마·TransportIcon·알림 폼을 재사용한다. 데이터·지도·알림 동작을 유지하고 UI와 브랜드 자산을 교체한다.
**Tech Stack:** 기존 Expo / React Native / TypeScript. 브랜드 이미지: built-in imagegen. PNG export: 기존 authoring sharp.
**Spec:** docs/design-system.md, docs/design-references.md

- [ ] 버스·지하철 캐릭터 자산과 공통 교통수단 아이콘을 생성하고 전체 화면의 형태를 통일한다.
- [ ] 알림 홈·저장 카드·교통수단 선택·반복 요일·시간·도착 조건을 카드 위계로 재설계한다.
- [ ] 검색·지도 컨트롤·바텀시트·도착 목록·시간표·의견 보내기를 같은 기준으로 정리한다.
- [ ] 타입·린트·대비·번들·실제 화면·네이티브 자산을 검증하고 연결된 아이폰에 설치한다.

새 의존성·테스트·커밋·배포를 추가하지 않는다. 공식 노선색·지도 좌표·정류소 선택·시간표와 실시간 데이터 구분은 보존한다. 작은 화면 줄바꿈·스크롤·44px 터치 영역·선택 대비·비활성 상태를 중점 검토한다.
