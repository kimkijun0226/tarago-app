# 확정 아이콘과 공통 UI 정리

사용자가 확정한 1번 H 심볼을 그대로 적용한다. 흰 바탕·파란 교통 말풍선·두 갈래 상단 요소를 유지하며 새로운 마스코트나 GO 로고를 추가하지 않는다.

- [x] 원본과 PNG, 앱 아이콘·스플래시·워드마크 연결
- [x] 색상 토큰: 맑은 파랑, 선명한 본문, 흰 카드, 옅은 파란 선택면
- [x] 공통 버튼·폼·알림 카드·지도 검색·지하철·의견 폼의 규격 정리
- [x] 선택 전후 레이아웃 고정, 공식 노선색 보존
- [x] 타입·린트·iOS/Android 번들 검사
- [x] iOS 시뮬레이터 알림 시작 화면·의견 화면 확인

API·알림 조건·지도 위치 계산은 변경하지 않는다. 네이티브 이미지 변경은 재빌드 후 아이폰에 반영된다.

검증: 선택 스타일은 색상만 변경. 주요 CTA 대비 5.24:1. 1번 아이콘 SVG는 확정 원본과 동일. PNG 1024×1024, 알파 없음. 네이티브 이미지 설정은 동기화했으며 실기기 네이티브 재빌드·설치는 이번 작업에서 실행하지 않았다.
