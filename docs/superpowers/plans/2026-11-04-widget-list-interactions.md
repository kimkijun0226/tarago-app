# 위젯 목록 조작 구현 계획

목표: 번호·내용을 길게 눌러 끌면 순서를 저장하고 홈 위젯·미리보기도 변경한다. 짧게 누르면 해당 정류소·역을 기존 지도 경로로 연다. 삭제는 분리한다.

- [x] 선택 목록과 같은 항목인지 검증하는 순서 저장 동작을 추가한다.
- [x] 기존 Gesture Handler로 길게 누른 드래그를 구현하고 저장 전에는 로컬 초안으로 표시한다. 저장 실패와 취소 시 기존 순서를 유지한다.
- [x] 기존 지도 Router 파라미터와 Query를 재사용한다. 새 버스 선택에는 좌표를 보관하고 기존 항목은 캐시·노선 상세에서 좌표를 찾는다.
- [x] 린트·타입 검사와 시뮬레이터에서 탭·길게 누르기·저장 유지·삭제 분리를 확인한다. 사용자 지침에 따라 테스트 파일은 추가하지 않는다.

검증: 린트·타입 검사, 실제 스토어/드래그 훅 임시 자체 점검(저장·위아래 이동·취소·중복 입력·저장 실패), 시뮬레이터의 접근성 순서 이동·미리보기 동기화·재진입 유지·탭 지도 이동·길게 눌렀을 때 지도 이동 억제를 확인했다. 연속 길게 끌기 제스처의 실제 손가락 조작은 아직 확인하지 않았다.
