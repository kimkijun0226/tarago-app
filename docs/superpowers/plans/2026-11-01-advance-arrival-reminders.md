# 장시간 도착 예약 알림

Goal: 버스·지하철 예약 알림에서 최대 60분 전부터 5분·10분마다 알리고, 10분 이내에는 선택한 단계(10·5·3·1분·곧 도착)로 전환한다.

- 기존 예약과 위치 반복 간격은 보존한다. 새 advanceRepeatMinutes(5|10)는 예약 시간 알림에만 적용한다.
- 시각·요일 밖, 오늘 종료·미루기 중에는 기존 조회·발송 차단을 유지한다.
- ETA가 없거나 60분보다 많이 남으면 허위 안내를 만들지 않는다. 시간표 보완은 기존 출처 표기를 유지한다.
- 같은 차량의 잦은 반복 전송은 실제 발송 내역의 간격과 DB 중복 키로 제한한다. 가까운 도착 단계가 시작되면 ETA가 다시 늘어도 이전의 반복 단계로 돌아가지 않는다.

Tasks:
- [x] 앱: 공유 예약 입력에 1시간 전 프리셋, 반복 간격 및 근접 시점 선택을 추가하고 검증/저장 타입을 확장한다.
- [x] 서버: 최대 60분 입력과 선택적 반복 간격 검증, 공유 발송 정책, 두 워커의 반복 간격·중복 방지를 연결한다.
- [x] 검증: 서버 타입·린트·회귀 테스트, 앱 타입·린트와 최종 diff를 확인한다. 앱 테스트 파일은 추가하지 않는다.

검증: 앱 타입·ESLint·iOS/Android 번들, 서버 타입·린트·전체 63개 테스트 통과. 실제 로컬 PostgreSQL에서 두 워커의 반복 간격·단계 전환·중복·ETA 역행을 확인했다. 실기기 푸시와 운영 배포는 미실행.
