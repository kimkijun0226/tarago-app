# TaraGo 브랜드 및 UI 완성도 개선 계획

**Goal:** 2–4px 라운드·제한된 그림자·청록과 살구 보조색을 적용하고 예약·버스·알림 스토리로 아이콘·로고·시작 화면을 통일한다.
**Architecture:** 기존 theme·공통 헤더·스타일을 재사용한다. SVG 원본에서 PNG를 생성하고 app.json에서 네이티브 자산을 연결한다.
**Spec:** docs/design-system.md
**Tech Stack:** 기존 React Native / Expo 57. SVG 및 기존 도구의 sharp로 PNG 생성.

- [x] 벡터 심볼·워드마크·플랫폼별 아이콘 생성 및 이미지 확인.
- [x] 화면별 작은 라운드와 선택·강조색, 지도 부유 그림자 반영.
- [x] 앱 아이콘·네이티브 스플래시·React 전환을 연결하고 prebuild 확인.
- [x] 타입·린트·iOS/Android 번들·시뮬레이터 화면 검증 및 diff 검토.

색상과 브랜드 도안은 사용자가 맡긴 범위에서 제안한 구현 선택이다. API·지도 좌표·저장·알림 규칙 변경, 배포·커밋·푸시는 하지 않는다. 실제 기기 Release 시작 화면은 별도 설치 검증이 필요하다.

## 검증 결과

타입·전체 린트·최종 iOS/Android export 통과. iPhone Debug 네이티브 빌드 서명 없이 성공. 1024px 아이콘·알파 채널·네이티브 연결·본문/버튼 대비 확인. 시뮬레이터 최신 알림 첫 화면 확인. 실제 기기 Release 시작 화면과 데이터가 있는 상세 화면 전체는 미검증.
