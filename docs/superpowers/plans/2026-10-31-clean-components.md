# 단정한 컴포넌트 구현 계획

**Goal:** 승인받은 Linear 참고 방향으로 순백색·중립 회색·검정 UI와 정렬된 컴포넌트를 적용한다.
**Architecture:** 기존 theme와 공통 컴포넌트를 재사용하고 화면 스타일만 수정한다. 데이터·지도·알림 동작은 유지한다.
**Tech Stack:** 기존 Expo / React Native / TypeScript. 추가 의존성 없음.
**Spec:** docs/design-system.md

- [x] 공통 팔레트에서 아이보리·카키 제거, 헤더·버튼 규격 정리.
- [x] 저장 알림 고정 높이 제거, 선택 영역 축소, 수정·삭제 장식 배경 제거.
- [x] 검색·버스·지하철 목록의 여백, 구분선, 아이콘 강조 정리.
- [x] 타입 검사·린트·iOS 번들 확인.
- [x] 시뮬레이터에서 최신 알림 첫 화면과 최종 diff 확인. 저장 알림 및 교통 상세의 실제 데이터 화면 전체는 수동 확인하지 못함.

기존 변경을 보존하고 신규 테스트·커밋·푸시·배포는 하지 않는다. 작은 화면의 줄바꿈, 선택 상태, 44px 터치 영역, 지도 컨트롤 위치, 공식 노선색 보존을 검토한다.
