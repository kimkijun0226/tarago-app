# 종료 상태 음성 알림 구현 계획

Goal: 버스 번호·지하철 방면과 ETA를 짧게 읽는 시스템 알림음을 앱 종료 상태에도 재생한다.

Architecture: 서버가 예약의 읽기 문구와 결정적 음성 키를 제공한다. 로컬 Expo 모듈이 앱 전경에서 한국어 TTS로 문구·공용 시간 조각을 생성하고 각 소리 파일을 준비한다. 준비 완료를 기기 인증 API로 확인한 예약만 푸시에 해당 음성 파일을 사용한다. iOS Library/Sounds와 Android FileProvider·예약별 채널을 사용하며 확장/외부 유료 TTS는 필요하지 않다.

- 음성은 설정에서 끌 수 있다. 준비 전·실패·ETA 결측은 기본 알림음을 유지한다.
- 1~60분·곧 도착·60분 초과를 지원하고 시간표 안내는 시간표 기준임을 읽는다.
- 기존 알림 액션·시간/위치 조건·조회 차단을 유지한다. 준비 메타데이터 변경은 액션 토큰을 만료시키지 않는다.
- 사용자 무음·집중 모드와 Android 강제 중지 제한을 우회하지 않는다.
- 앱 저장소 테스트 파일은 추가하지 않는다. 서버 회귀 테스트와 임시 네이티브/설정 검증을 사용한다.

Tasks:
- [x] 서버: 음성 계약·문구·키/파일 선택, 준비 인증 API와 두 워커 연결.
- [x] 앱: 음성 선택 UI·준비 큐·설정 저장과 로컬 Expo 모듈 연결.
- [x] iOS: TTS 파일 생성·표준 오디오 조합·Library/Sounds 정리.
- [x] Android: TTS·WAV 조합·FileProvider와 음성 채널 생성/정리.
- [x] 검증: 타입·린트·회귀 테스트·번들·네이티브 빌드. 실제 잠금/종료 푸시는 실행 여부를 구분해 보고한다.

검증 결과: 앱 타입·전체 ESLint·iOS/Android 번들 통과. iOS Debug·Release 전체 빌드, Android 모듈 및 앱 Kotlin·Manifest 병합 통과. 시뮬레이터에서 76개 한국어 음성 생성·캐시 재사용·정리 및 3개 예제 PCM 파형/길이 확인. 서버 전체 테스트 70개와 실제 로컬 DB·HTTP 준비 확인 검증 통과. 실제 아이폰·Android의 잠금/종료 후 APNs/FCM 소리 재생은 미실행이며 운영 서버 배포·앱 설치도 수행하지 않았다.
