# 원형 교통 위젯 구현 계획

사용자가 승인한 구성: 작은 위젯 4개, 큰 위젯 12개. 원 중앙에 버스 번호/호선과 교통 아이콘, 12시 방향에 남은 시간. 기존 버스 유형과 호선 색상 재사용. 가로형은 8개.

1. 위젯 저장/네이티브 검증 한도를 12개로 맞추고 선택 시 교통 색상을 함께 저장한다. 기존 데이터는 유지한다.
2. SwiftUI 홈 위젯을 크기별 원형 그리드로 바꾼다. 보이는 항목만 조회하고 기존 만료 처리와 접근성을 유지한다.
3. 앱 미리보기를 같은 구성으로 교체한다. 미리보기는 기존 캐시만 구독한다.
4. 타입·린트·Swift SDK 타입 검사와 한도/색상 검증을 수행한다. 실제 홈 화면 배치는 새 네이티브 빌드로 확인한다.
