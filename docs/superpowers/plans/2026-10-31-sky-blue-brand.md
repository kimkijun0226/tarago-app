# 밝은 파랑 알림 브랜드 적용 계획

**Goal:** 초록·청록을 제거하고 맑은 파랑·하늘색·소량의 노랑으로 친근한 알림 브랜드를 적용한다.
**Architecture:** 기존 공통 테마와 SVG→PNG 자산 경로를 재사용한다. 작은 라운드·목록 정렬은 유지하고 브랜드 심볼을 종·버스 표정으로 변경한다.
**Spec:** docs/design-system.md

- [x] 팔레트와 알림 진입 아이콘·설정 안내를 정리한다.
- [x] 종 모양 심볼·워드마크·iOS/Android 아이콘을 생성하고 확인한다.
- [x] 타입·린트·대비·양 플랫폼 번들 검증과 시뮬레이터 화면 확인.
- [x] 네이티브 자산 재생성 및 연결된 아이폰 설치.

공식 교통 노선 색상·지도 좌표·알림 규칙은 변경하지 않는다. 이전 iOS 시작 화면 캐시는 이번 요청 범위에서 추가 수정하지 않는다.

## 검증 결과

타입·전체 린트·iOS/Android export·서명된 iPhone Debug 빌드 통과. 연결된 실제 아이폰에 앱 삭제 없이 업데이트 설치하고 Metro 연결 실행 성공. 시뮬레이터에서 새 로고·첫 알림 추가 영역·줄바꿈 확인. 버튼/본문 대비 5.19/12.41, 보조 본문 대비 4.71. PNG 크기·알파와 마커 색 변경 전후의 동일한 알파 윤곽 확인. 실제 데이터가 있는 모든 상세 화면과 Release 시작 화면은 미검증.
