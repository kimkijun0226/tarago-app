# TaraGo 확정 브랜드

사용자가 선택한 1번 H 심볼을 채택했다. 원본은 explorations/return-to-one/01.svg에 보관한다. 흰 배경과 파란 교통 말풍선, 크기가 다른 두 상단 요소로 구성된다. SVG 원본에서 PNG를 생성하며 채택하지 않은 시안은 explorations/에만 보관한다.

- tarago-icon: 원본과 동일한 흰 배경의 앱 아이콘, 1024px 불투명 PNG
- tarago-mark: 투명 배경의 파란 심볼
- tarago-mark-white: 흰색 반전 심볼
- tarago-logo: 심볼과 TaraGo 워드마크
- tarago-adaptive / tarago-monochrome: Android용 안전 영역 전경

재생성: TARAGO_SHARP_MODULE=/path/to/sharp node scripts/generate-brand-assets.cjs

시작 화면은 흰 바탕과 파란 심볼을 사용한다. iOS·Android 네이티브 이미지 갱신에는 앱 재빌드가 필요하다.

2026-11-01: 사용자 요청에 따라 승인 심볼을 중심 기준 1.25배 확대했다. 원본 도형·비율은 유지하고 흰 여백만 줄였으며, 앱 아이콘·투명 심볼·워드마크에 같은 확대를 적용했다.
