# 공통 교통수단 아이콘

목록과 나의 알림은 shared/ui/transport-icon.tsx의 같은 플랫폼 심벌을 사용한다.

- iOS: bus.fill, tram.fill. iOS 지도 마커의 .ios.png는 같은 시스템 심벌을 로컬 렌더링한 이미지다.
- Android: directions_bus, tram. 지도 SVG·PNG도 Google Material Design Icons의 같은 심벌을 사용한다. 원본 https://github.com/google/material-design-icons 및 Material-LICENSE 참고.
- 마커 외곽·좌표 앵커·구분 색은 유지하며 내부 심벌만 통일한다.
