# 알림 아이콘

Phosphor Icons의 clock, map-pin duotone SVG를 타라고 팔레트와 크기에 맞게 수정했다. 둥근 코랄 외곽과 옅은 채움으로 게임 UI 느낌을 표현하며 종과 외부 배지는 사용하지 않는다.

- 원본: https://github.com/phosphor-icons/core/tree/main/assets/duotone
- 라이선스: MIT, 같은 폴더의 LICENSE 보존
- 스타일 참고: https://kenney.nl/assets/game-icons
- 앱은 로컬 PNG 1x·2x·3x를 사용한다. SVG는 수정용 원본이다.

search.svg는 타라고에서 직접 제작한 검색 아이콘이며 별도 Phosphor 심벌을 포함하지 않는다. 빨간 원형 검색 버튼 위의 흰 외곽과 옅은 하이라이트로 표현한다.
